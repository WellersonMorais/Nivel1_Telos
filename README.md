# 🧠 Treinamento Full-Stack — Nível 1: Fundamentos

Bem-vindo(a)! 👋  
Este repositório foi criado como parte do **programa de capacitação disponibilizado pela Télos**, voltado para o **treinamento full-stack**, composto por 8 níveis de aprendizado.

---

## 📘 Sobre este repositório

Aqui estão reunidas as **atividades práticas do Nível 1**, com foco na **revisão e absorção dos fundamentos de programação**.  
O conteúdo tem como objetivo fortalecer a base de programação e preparar o terreno para os próximos níveis do treinamento.

### 🧩 Conceitos abordados:

- Operações matemáticas e lógicas  
- Estruturas condicionais
- Estruturas de repetição
- Declaração e manipulação de variáveis  
- Criação e execução de funções simples  

---

## 🎯 Objetivo

O principal objetivo deste repositório é **registrar e revisar** os exercícios realizados durante o treinamento, promovendo:
- A **fixação do conteúdo teórico**;
- A **prática constante** das linguagens abordadas;
- E a **evolução gradual** ao longo dos níveis do programa full-stack.
